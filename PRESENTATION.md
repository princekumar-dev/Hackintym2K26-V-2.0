## Appendix — Q&A prep (don't present; memorise)
- **Why not ChatGPT?** → users can't read / type / prompt; we lock it to their textbook, scan-and-speak.
- **Already exists?** → none show source + confidence, serve all learners at once, or run low-bandwidth.
- **Blind kids have braille?** → braille reaches few; our main users are below-grade + language learners.
- **Just an LLM wrapper?** → the model's a commodity; the verify layer + accessibility + grounding is the work.
- **Hallucination?** → grounded to the page; low-confidence spans flagged, not guessed.
- **Real vs mock?** → answer honestly — judges respect it.
